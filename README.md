# Eternal Food

Eternal Food / 永恒食物 is a Minecraft Forge mod focused on food and food-related curios.

## Environment

- Minecraft: 1.20.1
- Forge: 47.4.20
- Java: 17

## Dependencies

- Curios API

## Current Content

- Nirvana Cookie / 涅槃曲奇
- Nirvana effect / 涅槃
- Phoenix Feather / 凤凰翎
- Mineral Gel / 矿物凝胶
- Mineral Scent effect and ore highlighting / 矿物嗅觉与矿物描边
